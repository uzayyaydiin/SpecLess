# Changelog

All notable changes to SpecLess will be documented in this file.

## v0.2.1

First public release of SpecLess.

### Added

- Model 1: Elliptical and Spiral galaxy morphology classification
- Model 2: Seyfert, Starburst, Star-forming, and LINER activity classification
- Pretrained XGBoost models
- Automated photometric feature construction
- KiDS and VIKING validation products
- DESI Legacy Surveys validation and portability products
- SHAP and feature-importance products
- Regression tests
- PyPI distribution as `specless-astro`
- Public GitHub release

### Installation

```bash
pip install specless-astro
