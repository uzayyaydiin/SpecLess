# Model 2 Validation

This directory contains validation products associated with SpecLess Model 2.

## native
Native SDSS+WISE model performance.

## kids_viking
KiDS/VIKING internal and external cross-survey validation results, including experiments with and without WISE photometry.

## interpretability
SHAP-based and XGBoost feature-importance tables for the four-class activity classifier.

Large underlying survey catalogues are intentionally not stored in this repository.
